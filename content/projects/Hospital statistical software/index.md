This operation manual aims to explain the performance calculation method of the software applied in departments, and develop a software for hospitals to summarize individual performance calculations. Utilizing the tkinter framework, it achieves real-time statistical calculation and application generation. By uploading performance tables, processing data, calculating individual bonuses, and generating result software, a hospital bonus performance processing and calculation software is developed.
